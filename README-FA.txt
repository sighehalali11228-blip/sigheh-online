راهنمای انتشار نسخه بدون پوشه assets

این نسخه برای آپلود آسان با گوشی آماده شده است. کدهای CSS و JavaScript داخل فایل‌های HTML قرار دارند؛ بنابراین نیازی به آپلود پوشه assets نیست.

1) ZIP را استخراج کنید.
2) وارد پوشه استخراج‌شده شوید.
3) همه فایل‌های HTML را انتخاب کنید، به‌ویژه index.html و صفحات شهرها.
4) در مخزن GitHub، Add file > Upload files را بزنید و فایل‌ها را در ریشه مخزن بارگذاری کنید.
5) Commit changes را بزنید.
6) بعد از انتشار، آدرس سایت را تازه‌سازی کنید.

ارتباط تلگرام: https://t.me/Ramezanzadehaj

نکته: فایل‌های رضایت مشتری فقط جای نمایش نظرها هستند؛ نظر واقعی را با اجازه صاحب آن درج کنید. سایت استاتیک است و عضویت/ورود یا پنل کاربران ندارد.
